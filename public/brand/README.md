# DrakeLabs logo assets

Three arrangements of the existing website identity:

- `mark`: boxed D / symbol.
- `wordmark`: DrakeLabs. lettering.
- `combined`: symbol and lettering together.

Each arrangement includes `light` artwork for navy/dark backgrounds and `dark` artwork for white/light backgrounds. SVG files contain outlined lettering, require no installed fonts, and scale to any size. PNG files are transparent exports at 4× the SVG dimensions.

Use the combined version where space permits, the wordmark in text-led headers, and the mark for compact placements. Preserve proportions and clear space. Standard artwork uses teal; holiday accents are a separate website treatment.
