# DrakeLabs on GitHub

Organization: https://github.com/DrakeLabs

Website source: https://github.com/DrakeLabs/drakelabs.github.io

Zach owns and manages the organization through his personal GitHub account. The organization uses a separate identity for portfolio and project repositories.

Only the Astro website belongs in this repository. Server backups, credentials, private configuration, and the surrounding workspace are excluded.

Future repositories may hold curated lab notes or reusable tools when those materials are ready to share. Each repository should have a deliberate license decision; third-party media artwork is not covered by a project-wide license.
